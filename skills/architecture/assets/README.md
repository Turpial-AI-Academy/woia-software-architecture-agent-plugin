# Assets

These assets are lightweight starting points for architecture work:

- [ADR.template.md](ADR.template.md) — durable architecture decision record.
- [architecture-report.template.md](architecture-report.template.md) — evidence-backed architecture review/report.
- [dependency-map.template.md](dependency-map.template.md) — textual dependency/boundary map.

Do not copy or fill every template mechanically. Use only the artifact that helps the task, preserve repository-native formats when they already exist, and adapt terminology to the system being reviewed.
